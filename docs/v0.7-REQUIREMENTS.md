# QVision v0.7: requirements (orchestrator) from the 2026-11-15 headset session

## User feedback (translated)
- **Server (Unreal via CloudXR):** "On the PC it looks good, but in the headset it looks glitchy. Some objects tremble, the glass has many errors (lines that appear and disappear), and the shadows aren't the same quality as on the PC. Use high quality / ultra."
- **Local app:**
  1. "Simplify the panel. Add **Undo** and **Back / Forward**."
  2. "Models should come in **correctly scaled**."
  3. "Flying should be **much faster**."
  4. "I added a very large model and it doesn't fit, because of the **sphere (globe)** of the immersive environment; it passes through it. I have very large models."
  5. "A **more professional start interface**, so I understand where I am."
  6. "A better-designed **app flow**: when I close the last window it should take me out of the app; entering it again shouldn't be glitchy. I got stuck inside a project."

## Decisions
| # | Requirement |
|---|---|
| S1 | Unreal "VR Ultra" = **baked GPU Lightmass** + **forward shading + MSAA 4×** + reflection captures + high screen percentage + stable glass. Lumen/TAA moves to an optional desktop profile. Vegetation is pre-decimated, because forward shading has no Nanite. |
| L1 | Panel redesign: compact sections. **Undo / Redo** cover object transforms, add, remove, hide and layer ops; both the panel and the hand/palm show them. **Back / Forward** = navigation history of *places*: every Recenter, fly session end, or teleport/camera jump stores a pose; Back/Forward move between poses. |
| L2 | **Import units:** auto-detect from bounds. If max extent > 2,000 m, assume cm (×0.01). If > 200,000 m, assume mm (×0.001). If < 0.05 m, assume the model was authored in meters but exported tiny, and don't scale it, just flag it. Show "Imported at real size W×D×H m (units: cm → m)" with a **Units** fix menu (m, cm, mm, in, ft) for the selected item, persisted per item. |
| L3 | **Fly speed:** the base curve is ×3 faster (cap 40 m/s × multiplier); the Fly speed slider goes 0.25×–10×. |
| L4 | **Sky never clips:** the sky dome and far ground **follow the user's head position** each frame (translation only), and the dome radius adapts to content (≥ 1.5 × the content's max extent, minimum 450 m, up to the far-plane limit). The near ground stays world-locked at y = 0. |
| L5 | **Pro home:**<br>• header with the QVision mark and a short tagline;<br>• a clear "you are here" title on every screen (Home › Project name);<br>• project cards with thumbnail or initial, date and object count;<br>• a clean empty state;<br>• Server tab restyled consistently. |
| L6 | **Flow:**<br>• **Leaving a project** (Leave or closing the panel window when no other QVision window is open) saves, closes the immersive space and returns to Home. If the user closed everything, the app ends: no windows and no immersive space open.<br>• **On launch**, restored panel, layers or inspector windows without an open project close themselves and open Home. Disable scene restoration for those windows (`.restorationBehavior(.disabled)` where available).<br>• **Opening a project twice quickly**, or opening while another is closing, is serialized: no stuck states. |
