## Approach: baked textures, generated offline (no downloads, no third-party assets)
Write `tools/make_environments.py` (Python 3, numpy + Pillow only, both installed) and RUN it to produce the textures. Inspect your results visually: open the PNG/JPGs with your Read tool and iterate until they look good. Keep the app light: total under 12 MB.

**1. Skies:** one equirectangular JPG per preset, 4096×2048, quality ~88.
- **daylight**: zenith deep blue → pale horizon haze, soft fBm cumulus clouds (domain-warped noise, lit tops / grey undersides, thinning toward the horizon), sun disk + glow at ~45° elevation.
- **sunset**: deep blue/violet zenith → orange/pink horizon, stretched cirrus clouds lit warm, sun ~5° above the horizon.
- **night**: navy → near-black, a dense star field (varied brightness, a faint milky-way band), moon with halo, faint horizon glow.
- **studio**: an architectural presentation "cyclorama": a clean, very soft neutral light-grey gradient, subtle vignette, no clouds.
- No seam at the u = 0/1 wrap: make the noise periodic in longitude.
- **Pole handling:** no pinching artifacts at the zenith.

**2. Floor material**, tileable 2048², per preset family:
- **daylight/sunset**: large-format polished concrete or stone pavers (1 m × 1 m slabs with thin dark joints, subtle per-slab tone variation, micro noise, light staining).
- **studio**: a seamless matte light-grey epoxy floor with a very faint 1 m measuring grid.
- **night**: the same pavers, darker and slightly wet-looking (lower roughness).
- Generate: albedo (JPG), normal map (PNG, tangent space from the height via Sobel, OpenGL +Y convention, which RealityKit expects), roughness (grayscale PNG). Seamless tiling is mandatory: periodic noise, and joints aligned to the tile edges.

**3. Horizon blend:** a radial gradient texture (e.g. 1024², white centre → transparent edge) to fade the floor into the sky.

## RealityKit build (`EnvironmentBuilder.make`)
- **Sky dome:** `MeshResource.generateSphere(radius: 450)`, scale `[-1, 1, 1]`, an `UnlitMaterial` with the sky texture. Fix the orientation so up is up and the sun matches the light direction. Verify the equirect mapping of `generateSphere` and flip U if your sun ends up mirrored.
- **Floor:**
  - **Near floor:** a disc/plane radius ~60 m, `PhysicallyBasedMaterial`: baseColor texture, normal texture, roughness texture, `textureCoordinateTransform.scale` so one texture tile = 4 m (2048 px tile containing 4×4 slabs of 1 m). Use a repeat sampler. Metallic 0.
  - **Far ground:** a second large disc (radius 440, at y = −0.01) using an `UnlitMaterial` coloured to the horizon colour, plus the radial-fade texture as an alpha/opacity, using `blending = .transparent(opacity:)` with the texture if supported; otherwise a vertex-free approach, e.g. several concentric rings with decreasing opacity. That way the floor edge is never visible and dissolves into the sky haze.
- **Lighting:**
  - IBL from the SAME sky image: load it as a CGImage, then `EnvironmentResource(equirectangular:)` (visionOS 2), `ImageBasedLightComponent` (name the entity `imageBasedLightName`), with intensityExponent tuned per preset (night dimmer).
  - Sun/moon: a `DirectionalLightComponent` aligned with the sun position in the texture, with shadows (`DirectionalLightComponent.Shadow`), intensity per preset. Keep the `#available` guards as now.
- **Loading:** `Bundle.main.url(forResource:withExtension:)` → CGImageSource → CGImage → `TextureResource(image:options: .init(semantic: .color | .normal | .raw))`. Use `.normal` semantic for normal maps and `.raw` for roughness. Cache per preset (static dictionary) so switching presets is instant the second time. Everything async; never block the main thread with decoding large images. Decode in a `Task.detached`, then create the TextureResource on the main actor.
- **Fallback:** if any resource is missing or fails, fall back to the current procedural version, so the app never shows nothing.
