```swift
import CloudXRKit
CloudXRKit.registerSystems()                       // once at app init (the orchestrator does this in QVisionApp)
var cfg = CloudXRKit.Config()
cfg.resolutionPreset = .standardPreset             // also .performancePreset, .recordingPreset
cfg.handTrackingMode = .prediction                 // device; .simulated in the simulator; .disabled
cfg.connectionType = .local(ip: "192.168.0.87")
let session: Session = CloudXRSession(config: cfg) // `Session` is the protocol type the sample stores
session.configure(config: cfg)
try await session.connect()
session.disconnect(); session.pause(); try session.resume()
session.state  // SessionState: .initialized .connecting .authenticating .authenticated .connected
               // .disconnecting .disconnected(Result<…, error>) .paused .pausing .resuming
// errors: case .disconnected(let result) → case .failure(let error): error.kind, error.localizedDescription,
//   cases like .failedConnectionAttempt, .invalidServerURL, .dns, .pauseTimeout, .sessionTerminatedUnknownReason
// Immersive: an Entity with components[CloudXRSessionComponent.self] = .init(session: session), added in a RealityView,
//   plus an invisible "gesture wall" (InputTargetComponent + trigger CollisionComponent box 40x40x0.01 at z = −20).
```
The sample observes `session.state` with `.onChange(of: appModel.session?.state)`, so the session is observable. Mirror that pattern. Use `switch` with a `default:` everywhere you match `SessionState` or error kinds, to stay compile-safe across 6.x minor versions.

## Contract (binding: the orchestrator's code calls exactly this)
```swift
// ServerModels.swift
struct StreamServer: Codable, Identifiable, Hashable { var id: UUID = UUID(); var name: String; var host: String }
enum StreamQuality: String, Codable, CaseIterable, Identifiable { case standard, performance; var id: String { rawValue }; var title: String }

// ServerSessionController.swift
@MainActor @Observable final class ServerSessionController {
    static let streamSpaceID = "stream"
    enum Phase: Equatable { case idle, connecting, connected, disconnecting, failed(String) }
    private(set) var servers: [StreamServer]          // persisted (JSON in Application Support or UserDefaults)
    private(set) var activeServerID: UUID?
    private(set) var phase: Phase
    var quality: StreamQuality                        // persisted
    var handTrackingEnabled: Bool                     // persisted, default true
    var showRoom: Bool                                // persisted, default false → Full immersion; true → Mixed
    var isStreamSpaceOpen: Bool                       // set by StreamImmersiveView onAppear/onDisappear
    init()
    func addServer(name: String, host: String)
    func updateServer(_ server: StreamServer)
    func deleteServer(_ id: UUID)
    func connect(to id: UUID) async                   // validates host, builds Config, creates/configures the session, connects
    func disconnect()
}

// ServerHomeView.swift
struct ServerHomeView: View   // reads @Environment(ServerSessionController.self); the "Server" tab of the main window

// StreamImmersiveView.swift
struct StreamImmersiveView: View   // content of ImmersiveSpace(id: ServerSessionController.streamSpaceID)
```
The orchestrator declares in QVisionApp:
```swift
@State private var server = ServerSessionController()
ImmersiveSpace(id: ServerSessionController.streamSpaceID) { StreamImmersiveView().environment(server) }
    .immersionStyle(selection: <binding from server.showRoom: true → .mixed, false → .full>, in: .mixed, .full)
```
and RootView shows `ServerHomeView().environment(server)` as a "Server" tab next to "Projects" (only when no project is open).

## Behaviour
- **ServerHomeView (main window tab)**:
  - **Header:** "Stream from a server" plus a one-line explanation ("Unreal Engine on your PC or the office server, streamed with NVIDIA CloudXR").
  - **Saved servers list:** each row has name, host and a **Connect** button. Context menu: Edit, Delete. Highlight the active server.
  - An **"Add server"** sheet with Name and IP/host fields. Validate IPv4 or a hostname. Port is fixed by CloudXR, so don't ask for it.
  - **Settings:** Quality (Standard / Performance), Hand tracking toggle, "Show my room (mixed)" toggle.
  - **Status area** driven by `phase`:
    - connecting: a ProgressView and "Connecting to <name>…";
    - connected: "Streaming", plus a big **Disconnect** button;
    - failed: a red message with the real error text, plus **Retry**.
  - **"How to test" disclosure:**
    1. Run CloudXR Runtime + an OpenXR app (e.g. NVIDIA's LÖVR sample, or Unreal) on the PC.
    2. Allow it through the firewall.
    3. Enter the PC's IP.
    4. The headset and PC must be on the same network.
  - **Opening and closing the immersive space** lives here, via `openImmersiveSpace` / `dismissImmersiveSpace`:
    - once `phase` becomes `.connected` and the space isn't open, open it;
    - when `phase` leaves `.connected`, dismiss it.
    - If opening fails, call `disconnect()` and show an error.
  - Per the sample's WindowStateManager, CloudXR may need the immersive space open for the stream to render. Read `WindowStateManager.handleConnectionEstablished` and mirror its exact order (connect → open space, or open space → connect).
- **StreamImmersiveView:**
  - A RealityView with the session entity (`CloudXRSessionComponent`) and the gesture wall.
  - `onAppear`/`onDisappear` set `isStreamSpaceOpen`.
  - Triple-tap (`.onTapGesture(count: 3)`, as in the sample) opens the main window if it's closed, using `openWindow(id: AppModel.mainWindowID)`. That's the escape hatch.
  - On `scenePhase == .background`, pause the session; resume on `.active`, as in the sample's iOS branch.
- **ServerSessionController:**
  - Keep the session as `@ObservationIgnored` storage and mirror its state into `phase`. Observe it through a Task that polls `session.state` every ~0.2 s while non-idle. Polling is OK and simplest; stop when idle or failed.
  - Map `.disconnected(.failure(error))` to `.failed(humanMessage)`, with hints:
    - failedConnectionAttempt → "Server not reachable: check the IP, that CloudXR Runtime is running, and the firewall";
    - invalidServerURL → "Invalid address".
  - Disconnecting returns to `.idle`.
  - Reuse a single session object: on reconnect, call `configure(config:)` then `connect()`, as the sample does.
