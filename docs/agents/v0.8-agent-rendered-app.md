# v0.8 agent: Rendered mode (app + QVision Library)

Scope: R1 (Home tabs), R3 (library server + app delivery), R4 (Rendered viewer) of `docs/v0.8-REQUIREMENTS.md`.

## PC side: `tools/library-server/`
| File | What |
|---|---|
| `qvision_library.py` | Python 3 stdlib only, `ThreadingHTTPServer`, port 8770, folder argument (default `C:\All Docs\06_Apple vision pro\assets\Rendered`). |
| `Start-QVisionLibrary.cmd` | Prints the PC's LAN IPv4 address(es) and URLs, then runs the server (`py -3`, falling back to `python`). Desktop shortcut: `Desktop\Vision Pro\QVision Library (PC).lnk`. |
| `add-library-firewall.ps1` | Admin, run once: inbound TCP 8770, Private profile, RemoteAddress LocalSubnet, group "QVision CloudXR". |

Endpoints:
- `GET /index.json` returns `[{id, title, file, sizeBytes, modified, thumbnail?, sidecar?}]`, regenerated on every request.
  - Only top-level `*.usdz` files are listed. `id` is the file stem.
  - `title` is the sidecar title, or the stem with `_` replaced by spaces.
  - `modified` is ISO 8601 UTC.
  - `sidecar` and `thumbnail` are file names (`<stem>.json`, `<stem>.jpg|.jpeg|.png`).
- `GET /files/<name>` streams the file with `Content-Length`, in 1 MiB chunks. HEAD is supported.
  - The decoded name must be a bare file name: no `/ \ : ..` or NUL.
  - It must match an existing top-level file of the folder, with an allowed extension (usdz, json, jpg, jpeg, png).
  - The real path is re-checked to sit directly inside the folder.
- Only private, loopback and link-local client addresses are served (IPv4-mapped IPv6 included); everyone else gets 403.
- Every request is logged as `client METHOD path -> status (bytes)`.

Tested locally with a temp folder: index, byte-identical download, 404 on traversal variants (`..%2F`, `%5c`, `C:%5C…`, subfolders, non-listed extensions), HEAD, and the LAN check.

### Storage
- Each scene lives in `Documents/Rendered/<id>/`: `<Name>.usdz`, `<Name>.json`, `<Name>.jpg` and `.qvision-origin.json`. The origin file records the library id, size and modified date, so the UI can show "Update" when the PC copy changes.
- Downloads and imports are staged in `Documents/Rendered/.partial-<uuid>/`.
  - The download order is: sidecar (required if listed), then thumbnail (optional), then the USDZ.
  - The USDZ comes through a `URLSessionDownloadTask`, and its temp file is moved inside the completion handler. Progress is polled from `countOfBytesReceived` every 0.25 s.
  - After the transfer, the size is verified against the index.
  - Only then is the staging folder renamed to its final name (an existing older copy is swapped atomically).
- A cancel or failure deletes the staging folder. Leftover `.partial-*` folders are removed at launch.
- A free-space check runs before downloading (size + 200 MB).
- The PC address defaults to the saved server whose name contains "My PC" (or the first saved server). A typed override (`host` or `host:port`) is stored in UserDefaults `rendered.libraryHost`.

### Viewer (R4)
- **Entity tree:** `root → worldRoot (fly) → placement → scene`, with the `sky` under `worldRoot`.
- **Loading:** `Entity(contentsOf:)` loads asynchronously, off the main thread. Phase messages: Opening / Loading / Preparing (determinate). Files over 1.5 GB are refused up front. A load failure gives a clear message that mentions the ~500 MB budget when the file is large.
- **Material conversion:** every `ModelComponent` material is converted.
  - `PhysicallyBasedMaterial` becomes `UnlitMaterial(applyPostProcessToneMap: false)`. It keeps the base-colour tint and texture, the face culling, the opacity threshold, and `.transparent(opacity:)` when the opacity scale is < 1 or there is an opacity texture.
  - An existing `UnlitMaterial` is rebuilt without tone mapping.
  - ShaderGraph materials are left as they are.
  - Tone mapping is disabled because the bake is already tone-mapped, so the headset shows the bake's exact sRGB values.
- **Stripped components:** grounding shadow, IBL and IBL receiver, and directional, point and spot lights. Nothing is added.
- **Placement:** `placement = T(feet) · R_y(headYaw − startYaw) · T(−start)`.
  - `feet` is the head position projected to y = 0 (the ImmersiveSpace origin is on the floor). With `eyeHeightIncluded: true` it is the head itself.
  - The sidecar point and direction are mapped through the loaded root's own transform.
  - **Yaw convention:** a right-handed rotation about +Y of the scene's −Z axis (0 = look along −Z, 90 = along −X).
  - Without a sidecar: the bounds centre at the bounds' min y, looking along −Z.
  - If no head pose exists yet, placement is redone on the first pose.
  - **Start** re-places the scene where the user physically stands now.
- **Sky:** `EnvironmentBuilder.makeSkyOnly(.daylight)` (new: sky dome only, unlit) is added unless the scene has its own sky.
  - The scene counts as having a sky when the sidecar says `hasSky: true`, an entity name contains "sky", or the bounds exceed 1.5 km.
  - The dome radius is clamp(1.5 × the scene's max extent, 450 m, 5 km), and the dome follows the head every frame.
- **Fly:** a dedicated `FlyController(hands: model.hands)`, so it has the same speed curve as Projects. Speed 1×–10× is stored in UserDefaults `qvision.renderedFlySpeed`. It is always enabled while the scene is shown.
- **Release:** `release()` cancels the load (token), disables fly, removes the scene and sky, and resets the transforms. It runs on Exit and on space disappear.

### Flow (L6 rules, AppModel)
- **State:** `AppModel.renderedSpaceID = "rendered"`, plus `renderedState`, `currentRenderedScene`, `homeTab` and `rendered: RenderedViewer`.
- **Open / Exit:** `requestOpenRendered` / `requestLeaveRendered` run through the same serialized `enqueueFlow` as projects.
  - **Open:** an open project is saved and closed (`performLeave(toHome: true)`), a server stream is ended (`endStreamIfNeeded`, which waits for the stream space to close), and a previous rendered scene is closed. Then the scene loads and the space opens (`syncRendered`, mirroring `syncStage`).
  - **Exit:** opens Home first, sets the tab to Rendered, dismisses the space, then releases the scene.
- **Other spaces:** `performOpen` (project) also closes the rendered space and ends a stream first. The Server tab's Connect / Retry call `releaseImmersiveSpacesForStream()` first. Only one of stage, rendered or stream is ever open.
- **Main window:** RootView shows `RenderedSessionView` while a scene is open.
  - When the scene is ready and hand tracking runs, it dismisses the main window once per open, and the palm menu takes over.
  - Without hand tracking the window stays as the controller. Closing it then leaves the scene (`leaveRenderedIfUncontrollable`).
  - A load failure while no window is open reopens the main window.
- **Leaving with the Digital Crown / system:** `renderedDidDisappear` releases everything and switches Home to the Rendered tab.

## Known limitations
- The thumbnail and sidecar are fetched whole (small files). Only the USDZ shows progress. Downloads don't resume after an interruption; they restart.
- `Entity(contentsOf:)` has no progress callback, so "Loading" is indeterminate. Only the material pass is determinate.
- ShaderGraph (MaterialX) materials are not converted.
- The baked daylight sky texture stays in EnvironmentBuilder's shared texture cache after exit (it is shared with Projects). The scene itself is fully released.
- Mixed immersion isn't offered for Rendered (full only); R4 makes it optional.
