## StageController
- Add `contentRoot` (child of worldRoot). Items are parented to `contentRoot`; persisted transforms are in contentRoot space.
- **Real size:** `addItem(freshPlacement: true)` must NOT rescale.
  - Pivot bottom-centre: offset the content child by −(center.x, min.y, center.z) of its bounds, measured relative to the item root.
  - Place the root at `placement` with y = 0, then push it along the user→placement horizontal direction until the item's near face is ≥ 0.8 m from the user. Approximate using half of max(width, depth).
  - The cube primitive is 0.3 m.
  - Apply `item.hiddenParts` (set `isEnabled = false` on those paths) for fresh and non-fresh placements alike.
- `placementPoint`: same head-based logic as v0.2, but in **contentRoot** space with y = 0, at 1.6 m forward and spread by slot. Convert world → contentRoot.
- **Scene scale** `setSceneScale(s, tabletop)`:
  - Compute the pivot once per call from all visible items' combined bounds in contentRoot space: footprint centre (cx, 0, cz). If there are no items, use the placement point.
  - Set `contentRoot.scale = [s, s, s]` and `contentRoot.position = pivot·(1 − s) + (tabletop && s < 0.999 ? [0, 0.75, 0] : 0)`. contentRoot has no rotation.
  - Store s; selection-indicator thickness must account for it.
- **Floor:** `dropToFloor(id)` sets the item's y so that `visualBounds(relativeTo: contentRoot).min.y == 0` and returns the new transform. `snapToFloorIfClose(id, worldThreshold:)` converts the threshold to contentRoot units (÷ s), snaps if |min.y| < threshold, and returns whether it snapped.
- **Inspect:**
  - `setInspectMode(true)`: for every item, remove the root CollisionComponent (keep it stored), and add a box CollisionComponent + InputTargetComponent to every descendant that has a ModelComponent. Size the box from `visualBounds(relativeTo: thatEntity)`, minimum 1 cm.
  - `false` restores the root collider and removes the part colliders. Respect locked layers (no InputTarget).
- `partID(for:itemID:)`: the path of entity names from the item's content child down to the entity, joined with "/". An empty name becomes "#<childIndex>".
- `inspect(itemID:partID:)` → `InspectionInfo`:
  - walk the content hierarchy depth-first;
  - per ModelComponent mesh, count `mesh.contents.models` → `parts`: vertices = `part.positions.count`, triangles = `(part.triangleIndices?.count ?? 0) / 3`;
  - materials = `modelComponent.materials.count`;
  - `size` = `visualBounds(relativeTo: contentRoot).extents` (real meters at scene scale 1);
  - animations = `availableAnimations.count`;
  - fileName and size come from the asset URL (keep the URL per item). Use `FileManager.attributesOfItem` for the size.
  - Aggregate per part (node + descendants). Cache per item, invalidated on setPartHidden.
  - Guard performance: stop walking after 20,000 nodes.
- `setPartHidden` toggles `isEnabled` on that path.

  - When `left.isTracked && left.palmFacingUser`:
