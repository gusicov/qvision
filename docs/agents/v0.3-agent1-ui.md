## ProjectPanelView(context: .hand | .window)
The project panel. In `.hand` it's ~520 pt wide and at most ~720 pt tall, with an internal ScrollView. Sections, compact and visionOS-styled:
1. **Header**: project name; a **Pin** toggle button (`pin` / `pin.fill`, bound to `isHandPanelPinned`, `.hand` context only).
2. **Mode**: Edit / Inspect segmented control (`interactionMode`). Switching to Inspect opens the Inspector window: `openWindow(id: AppModel.inspectorWindowID)` if `!isInspectorWindowOpen`.
3. **View**: Mixed / Immersive; Environment picker when Immersive.
4. **Scale**: label "Scale 1:N" with N = round(100/percent) and the percent shown; a Slider 1…100 (step 1) bound to `sceneScalePercent`; quick buttons 1 · 5 · 10 · 25 · 50 · 100 %; a "Table height" toggle (enabled only when percent < 100).
5. **Placement**: "Snap to floor" toggle; "Drop selected to floor" button (disabled without a selection).
6. **Navigate**: Fly mode toggle plus hint; a "Fly speed" slider 0.25…4 (`flySpeed`, show "1.0×"); Recenter.
7. **Scene**: Import models (`.fileImporter`), Add test cube, Reset scene; show `importProgress` with a ProgressView when non-nil.
8. **Objects**: the list from v0.2 (select, eye, … menu with Duplicate / Move to layer / Drop to floor / Delete).
9. **Footer**, pinned at the very bottom, outside the ScrollView: two large buttons, **Layers** (`square.3.layers.3d`; toggles the Layers window via `openWindow` / `dismissWindow(id: AppModel.layersWindowID)` based on `isLayersWindowOpen`) and **Leave** (`rectangle.portrait.and.arrow.right`, destructive tint).

**Leave sequence:** `openWindow(id: AppModel.mainWindowID)` → `model.closeProject()` → `dismissWindow(id: layers)` and `dismissWindow(id: inspector)` if open → `await dismissImmersiveSpace()`.

**Background:** apply `.glassBackgroundEffect()` in the `.hand` context (the Stage agent doesn't add one); none in `.window`, where the window provides it.

## LayersWindowView / InspectorWindowView
- **LayersWindowView**: `LayersPanelView(compact: false)` inside a NavigationStack titled "Layers". `onAppear`/`onDisappear` set `isLayersWindowOpen`. With no open project, show "Open a project first".
- **InspectorWindowView** (NavigationStack "Inspector"; `onAppear`/`onDisappear` set `isInspectorWindowOpen`):
  - If `interactionMode != .inspect`: a note plus a button to switch to Inspect.
  - If `inspection == nil`: "Tap a model to inspect it".
  - Otherwise:
    - a summary card: name, file, size in MB, dimensions "W × D × H m" (x, z, y), and at the current scene scale "at 1:N: …";
    - stats: triangles (formatted, e.g. 1.2 M), vertices, meshes, materials, animations;
    - a **Parts** list, indented by depth: name, mesh icon, triangle count, size, an eye toggle (`setPartHidden`), with `selectedPartID` highlighted. Tapping a row calls `selectPart(itemID:partID:)`.
  - Use a lazy List; a model can have thousands of parts. Cap at the first 2000 and show "+N more".
