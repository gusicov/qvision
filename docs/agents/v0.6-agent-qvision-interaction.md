## Required behaviour
1. **New default mode "View" (locked):**
   - Make `InteractionMode` = `.view`, `.edit`, `.inspect` (titles "View", "Edit", "Inspect"; icons lock / hand.draw / info.circle).
   - In `.view`, NO item is hit-testable: remove InputTargetComponent from all item roots and parts, so gaze and pinch pass through models to windows, the palm button and attachments. HoverEffect must not highlight models in `.view`.
   - Every project opens in `.view`. The panel's Mode picker shows all three, with a one-line hint per mode.
   - `.edit` = today's behaviour (respecting locked layers). `.inspect` = today's inspect.
2. **Flying never moves models:**
   - While `isFlyModeEnabled` is true, behave like `.view` for hit-testing (models not targetable), whatever the mode. Restore when fly mode turns off.
   - Also make every gesture handler ignore input while `model.fly.isFlying` (or within 0.3 s after release), as a belt-and-braces guard.
3. **UI priority:**
   - The palm "Panel" button attachment should win over models: ensure it has its own InputTargetComponent and collision, and render it unoccluded if feasible. Consider `ModelSortGroupComponent` / depth-pass options only if you're sure of the API; otherwise rely on the hit-testing fix in 1 and 2.
   - In `.edit`, don't give items a collision box larger than needed: keep the tight bounds.
4. **Persistence:** none is needed beyond today's (the mode resets to `.view` on open).
5. **Docs:** update `README.md` (Features) with one line about View / Edit / Inspect.
