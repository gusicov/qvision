# QVision v0.3: requirements (orchestrator's interpretation) and contracts

## A. What the user asked for → precise requirements
| # | User request | Requirement |
|---|---|---|
| R1 | "The floor is the bottom of the model; everything at correct scale" | Imports keep their **real size** (USD meters, no auto-fit). On placement the model's **bottom sits on the floor** (y = 0 of `contentRoot`). |
| R2 | "Magnetic floor so objects go down easily / everything placed on the floor at first" | **Snap to floor** (project setting, default ON). While dragging, if an item's bottom comes within 10 cm (real-world) of the floor, it snaps exactly onto it. There's also a **"Drop to floor"** action for the selected item. All new items start on the floor. |
| R3 | "Each object added should have its exact size" | Same as R1. The test cube is 30 cm. Placement distance adapts to the model's size so big models aren't placed on top of the user. |
| R4 | "Scale area in the panel: 1…100, 100 = real scale" | **Scene scale** slider 1–100 % (+ quick buttons 1, 5, 10, 25, 50, 100) applied to the **whole project** (`contentRoot`). The pivot is the content's footprint centre on the floor, so the model shrinks in place. **Table height** toggle: when scale < 100 %, lift the content to 75 cm so a scaled building sits like a table model. Persisted per project. |
| R5 | "Fly mode more sensitive the farther you move from where you clenched" | Nonlinear speed curve: small motions stay precise, larger motions get much faster, up to a higher top speed. **Fly speed** multiplier in the panel (0.25×–4×). |
| R6 | "Remove Layers from the palm; when you raise the left hand palm toward your face, a panel appears to the right of the hand: the project panel" | **Hand panel**: after a project starts, the project panel lives next to the LEFT hand. It appears ~16 cm to the right of the palm (toward the body midline), facing the user, while the left palm faces the user. It has a short grace period when the hand turns away, a **Pin** button to leave it floating in place, and a fallback to a normal window if hand tracking is unavailable. The main window closes while a project is open. |
| R7 | "At the very bottom: Layers and Leave" | The hand panel footer has **Layers** (opens/closes the Layers window) and **Leave** (save, close the stage, back to All Projects). |
| R8 | "Layers opens a separate panel you can move (Vision Pro window bar)" | Layers is a real **visionOS window** (`WindowGroup(id: "layers")`), so it gets the system move bar. |
| R9 | "Inspect mode: nothing moves; selecting shows info about the model and its internal layers" | `interactionMode = .inspect`. Move/scale/rotate are disabled. Tap selects an item AND the specific sub-part you hit. An **Inspector window** (movable, `WindowGroup(id: "inspector")`) shows: name, file, file size, real dimensions W×D×H (and at the current scene scale), triangles, vertices, meshes, materials, animations, plus a **part tree** of the model's internal hierarchy ("layers inside the USDZ"). Each part shows its own stats and an eye toggle to hide it (persisted). |
| R10 | "Why won't a 110 MB USDZ open?" | (1) Sign the app with the **Increased Memory Limit** entitlement (iloader Vision path; done by the orchestrator). (2) Import through `NSFileCoordinator`, so iCloud files download fully first, with the copy off the main thread and visible progress ("Copying… 110 MB", "Loading…"). (3) Clear error messages. (4) Docs: optimisation tips. |

## B. Scene graph (v0.3)
```
root
├─ fly.indicator
├─ handPanel attachment (world space, positioned per frame)
└─ worldRoot                       ← FlyController moves this (translation + yaw)
   ├─ environmentRoot             ← sky + ground (Immersive only); ground at y = 0
   └─ contentRoot                 ← scene scale + pivot + table height
      └─ item roots (ItemComponent)
```
- The floor is **y = 0 in contentRoot space** (equal to worldRoot y = 0 when the table height is off).
- Item transforms (persisted) are relative to **contentRoot**.

## C. Contract changes (binding)
### Models.swift (orchestrator, done)
- `Project`: `sceneScalePercent: Double?` (nil = 100), `isTabletop: Bool?`, `snapToFloor: Bool?` (nil = true). Accessors: `scenePercent`, `tabletop`, `snapsToFloor`.
- `ProjectItem`: `hiddenPartPaths: [String]?`, accessor `hiddenParts: Set<String>`.
- New: `enum InteractionMode { edit, inspect }`, `struct PartInfo`, `struct InspectionInfo`.

### AppModel (Agent 1): changes to the v0.2 contract
- **REMOVE** `isLayersPanelVisible`.
- **ADD**:
```swift
static let layersWindowID = "layers"
static let inspectorWindowID = "inspector"
var interactionMode: InteractionMode            // didSet: stage.setInspectMode(== .inspect); inspection = nil; selectedPartID = nil
var sceneScalePercent: Double                    // computed from currentProject.scenePercent; set: clamp 1...100, persist, stage.setSceneScale(Float(v/100), tabletop:)
var isTabletop: Bool                             // computed/persisted; set -> stage.setSceneScale
var snapToFloor: Bool                            // computed/persisted (default true)
var flySpeed: Float                              // stored 0.25...4, default 1; didSet fly.speed = flySpeed
var isHandPanelPinned: Bool                      // stored
var isLayersWindowOpen: Bool                     // set by LayersWindowView onAppear/onDisappear
var isInspectorWindowOpen: Bool                  // set by InspectorWindowView onAppear/onDisappear
private(set) var inspection: InspectionInfo?
private(set) var selectedPartID: String?
var importProgress: String?                      // human-readable status while importing/loading, nil otherwise
func selectPart(itemID: UUID, partID: String?)   // sets selectedItemID, selectedPartID, inspection = stage.inspect(itemID:partID:)
func setPartHidden(itemID: UUID, partID: String, hidden: Bool)  // persists hiddenPartPaths, stage.setPartHidden, refresh inspection
func dropSelectedToFloor()                       // if let t = stage.dropToFloor(id) -> itemTransformChanged
```
- `importAssets` / `addTestCube` now call `stage.addItem(item, assetURL:, freshPlacement: true, placement: stage.placementPoint(devicePose:slot:))`. `duplicateItem` passes `freshPlacement: false`.
- `openProject` additionally calls `stage.setSceneScale(...)` and `stage.setInspectMode(false)`, and resets `interactionMode = .edit`.

### StageController (Agent 2): changes to the v0.2 contract
```swift
let contentRoot: Entity                                       // NEW; items live here
@discardableResult func addItem(_ item: ProjectItem, assetURL: URL?, freshPlacement: Bool, placement: SIMD3<Float>) async throws -> Transform
    // freshPlacement: keep native size, pivot bottom-centre, bottom on floor (y=0), XZ at `placement`
    // pushed back so the near face is >= 0.8 m in front of the user; returns transform (contentRoot space).
    // !freshPlacement: apply item.transform. Both: apply item.hiddenParts.
func placementPoint(devicePose: simd_float4x4?, slot: Int) -> SIMD3<Float>     // now in contentRoot space, y = 0
func setSceneScale(_ scale: Float, tabletop: Bool)
func dropToFloor(_ id: UUID) -> Transform?                     // moves item so bounds.min.y == 0 (contentRoot space)
func snapToFloorIfClose(_ id: UUID, worldThreshold: Float) -> Bool
func setInspectMode(_ on: Bool)                                // per-part box colliders on, root collider off (and back)
func inspect(itemID: UUID, partID: String?) -> InspectionInfo?
func setPartHidden(itemID: UUID, partID: String, hidden: Bool)
func partID(for entity: Entity, itemID: UUID) -> String?       // path of names from item content root, e.g. "Building/Floor_2/Wall_12"
```
Unchanged: `root`, `worldRoot`, `load`, `clear`, `removeItem`, `setTransform`, `apply`, `setEnvironment`, `setSelected`, `entity(for:)`, `refreshSelectionIndicator`.

### StageView (Agent 2)
- **REMOVE** the palm "Layers" button and the floating layers attachment.
- **ADD** the "handPanel" attachment: `ProjectPanelView(context: .hand)`.
- Gestures: in `.inspect` they don't move anything, and tap calls `model.selectPart(itemID:partID:)`. In `.edit`, drag snaps to the floor when `model.snapToFloor`.
- If `model.hands.status != .running` 3 s after appearing, call `openWindow(id: AppModel.mainWindowID)` as a fallback (once).

### UI (Agent 1)
- `ProjectPanelView(context: .hand | .window)` replaces `ProjectWorkspaceView` (delete that file).
- `LayersWindowView` and `InspectorWindowView` are the window roots. `RootView` dismisses the main window once the stage is open AND `hands.status == .running`. "Leave" does: `openWindow(main)` → `closeProject()` → `dismissWindow(layers)` + `dismissWindow(inspector)` → `dismissImmersiveSpace()`.

### FlyController (Agent 3)
- New speed curve. `speed` is still the multiplier (now set from `AppModel.flySpeed`). Public API unchanged.
